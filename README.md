# Sensors and Process Control Systems — Handwritten Notes Website

A complete handwritten-style notes website. Every topic of the syllabus has its
**own `.html` file**, so you can open, print or share a single topic on its own.

## Open the site

Open **`index.html`** in any browser (double click is enough — no server needed).
`index.html` holds the master table of all 27 topics.

## Features

- **55 hand drawn diagrams** made with inline SVG (circuit symbols, block
  diagrams, characteristic curves). They stay sharp at any zoom and print well.
- **Blue / Red / Green** buttons on every page change the pen colour.
- **Print** button gives a clean black-on-white copy (the notebook background and
  the tool bar are hidden by the print stylesheet).
- **Previous / Next** buttons at the bottom of every page.
- Fully responsive for mobile.

## Fonts and offline use

The pages ask for the Google hand fonts **Caveat** (headings) and
**Patrick Hand** (text). If there is no internet, the browser falls back to the
handwriting fonts already installed on the computer (`Segoe Print` on Windows,
`Bradley Hand` / `Chalkboard SE` on macOS, `Comic Sans MS` elsewhere), so the
notes still look handwritten offline. Everything else — CSS and all diagrams —
is local, so the site works without any internet connection.

## Rebuilding / editing the notes

The pages are generated by Python scripts, so the same layout is used everywhere:

```
python3 build_a.py      # topics 1 - 11
python3 build_b.py      # topics 12 - 27
python3 build_index.py  # index.html
```

`helpers.py` holds the sketchy SVG symbol library (resistor, thermistor, LDR,
op-amp, SCR, TRIAC, MOSFET, relay coil, solenoid, motors, valves …) and the page
template. To change the look of every page at once, edit `css/notes.css`.

## Built-in checks

```
python3 verify.py    # HTML parses, every SVG is valid XML, all links resolve,
                     # every symbol reference exists
python3 layout.py    # geometry audit: labels clipped off the canvas or
                     # dropped inside a component box
```
